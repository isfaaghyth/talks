One-shot, or a conversation?
Stateless · one turn
runSingleTurnAsync()
runner.runSingleTurnAsync(prompt)
  • Called on the AgentRunner
  • Starts fresh every call, no memory
  • Can still chain tools within the turn
  • Best for one-shot commands
Stateful · many turns
runAsync()
runner.getOrCreateSession(chatId).runAsync(prompt)
  • Called on a session
  • Keeps history across turns for you
  • Agent can ask back, user can correct
  • Best for chat; reset with session.delete()
AssistantViewModel.kt · sessions keep history for you
// 1. Get or create an isolated session for the current chatval session = runner.getOrCreateSession(chatId)// 2. Run a turn (history is preserved automatically across turns)session.runAsync(prompt).collect { event -> when (event) { is AgentEvent.FunctionCall -> showToolRunning(event) is AgentEvent.FunctionResponse -> showToolCompleted(event) is AgentEvent.TextMessage -> responseMessage += event.text }}// 3. Clear history when the user taps "New conversation"session.delete()
